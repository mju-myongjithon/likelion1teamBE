# 1. 🦁 서비스 소개
**띵춘**은 명지대학교 학생이라면 누구나 학교 이메일 인증만으로 가입해서, 관심 태그 기반으로 맞춤 소식을 추천받고 함께할 사람을 모집·신청할 수 있는 캠퍼스 커뮤니티 서비스입니다.

- 학교 이메일(`@mju.ac.kr`) 인증으로 재학생만 가입 가능
- 관심 태그(공모전, 스터디, 동아리 등)를 골라두면 메인 화면에서 맞춤 소식을 확인
- 스터디·공모전·행사 등 모집글을 올리고, 참여 신청 → 수락/거절까지 한 번에 처리
- 명지대학교 공지사항을 자동으로 크롤링하고 AI로 태깅해서 모집글과 함께 검색 가능

### 팀 규칙 (아래는 예시입니다.)
1. 말 아끼다가 :poop:된다.  
좋은 아이디어가 있어도 말하지 않는다면 아무도 모릅니다. 설령 확신이 없는 의견이었더라도 팀에게 영감을 불어넣어줄 수 있습니다.
2. 롤링롤 (Rolling Role)  
역할을 돌아가면서 함으로써 한 명이 계속 어려운 역할, 혹은 쉬운 역할을 하지 않습니다.
3. 근거 있어? 근거 있냐고!  
당신이 의견을 제시할 때는 근거를 제시해주세요. 근거가 없다면 의견에 대해 동료들은 당신의 의견에 동의하기가 어렵습니다.
4. 지각은 지갑을 앗아간다.  
당신의 지각은 당신의 지갑을 울게 합니다. 지각 1회 시 당신이 회식 자리에서 지불할 값이 1+1/5+1 가 됩니다.
5. 영상보다 실물이 이쁘세요.  
만날 수 있는 경우에는 만나서 업무를 진행합시다. 비대면으로 진행하는 경우보다 대면으로 진행하는게 더 즐겁습니다.
6. 나 그거 싫었어. 아 그랬구나~  
감정 회고는 중요합니다. 서로의 감정을 공유하면 팀은 더 화목해지고 끈끈해질 것입니다.
8. TRT (Try, Refactor, Throw your table)  
일단 해봐라, 그리고 다시 해봐라, Just Do It! 정 안되면 모든 팀원에게 자신의 상황을 공유해라. 시도해 보는 것을 두려워 하지 말라. 
9. 당신의 머리를 믿지 마라. 당신의 글씨를 믿어라.  
기록은 중요합니다. 아무리 회의 때 좋은 의견이 나와도 정리하지 않으면 곧 날아갈 아이디어입니다. 정리하고 공유하는 습관을 가집시다.
10. 최선을 다 하면 온 우주가(팀원들) 당신을 도와줄 것이다.  
팀원이 열심히 무언가를 한다면, 다른 팀원들이 그것을 무시할 리 없습니다.

# 3. :computer: 핵심 기능

### 회원가입 / 인증
- 학교 이메일(`@mju.ac.kr`) 인증번호 발송 및 확인 (Gmail SMTP 실제 메일 발송)
- 인증 완료 후 소속 정보(과정·캠퍼스·단과대학·학과·학번) 등록
- 관심 태그(9종, 3개 이상) 선택 및 저장

### 마이페이지
- 내 프로필(이름/학과/캠퍼스/관심 태그) 및 활동 통계(내가 쓴 글 수, 참여한 모임 수) 조회
- 내가 쓴 모집글 + 신청한 모집글을 활동 목록 하나로 통합해서 최신순으로 확인
- 신청 상태(신청대기중 / 참여확정 / 거절) 실시간 확인

### 모집글 / 참여 신청
- 프로젝트·학교행사·공모전·스터디 등 카테고리별 모집글 작성 및 상세 조회
- 모집글 참여 신청, 작성자의 신청자 목록 조회 및 수락/거절 처리
- 수락 시 모집 인원 자동 반영, 정원 도달 시 자동 마감

### 검색
- 모집글과 학교 공지사항을 키워드 하나로 통합 검색

### 학교 공지 크롤링 & AI 태깅
- 명지대학교 홈페이지 공지사항을 주기적으로 자동 크롤링
- Gemini API 기반으로 크롤링된 공지에 자동 태깅

# 4. :department_store: 프로젝트 구조
도메인 단위 패키지 구조로 구성되어 있습니다.

```
com.lionking.ddingchun
├── auth        # 이메일 인증
├── user        # 회원가입, 마이페이지
├── post        # 모집글
├── application # 모집글 참여 신청/수락
├── search      # 통합 검색
├── crawler     # 학교 공지 크롤링, AI 태깅
└── global      # 공통 응답/예외 처리, 설정
```

각 도메인은 `controller` / `service` / `repository` / `entity` / `dto` / `exception`으로 나뉘며, 예외는 전부 `BusinessException`을 상속해 `GlobalExceptionHandler`에서 공통으로 처리합니다.

# 6. :rocket: 실행 방법

1. `.env.example`을 참고해 `.env` 파일 생성 (DB 계정, Gmail 앱 비밀번호 등)
2. `docker-compose up -d`로 로컬 PostgreSQL 실행
3. `./gradlew bootRun`으로 서버 실행 (기본 포트 8080, context-path `/api`)
4. `http://localhost:8080/api/swagger-ui/index.html`에서 API 문서 확인
